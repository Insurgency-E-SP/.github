## 🚀 Why Choose Insurgency ESP?

Insurgency punishes slow reads. The overlay keeps boxes, class, and distance in one layer so a silhouette in a doorway becomes a decision. Objective markers add mode context that plain player ESP leaves out.

Each element toggles independently, which keeps night maps and smoke-heavy pushes readable without a cluttered screen.
